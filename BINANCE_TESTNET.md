# Binance Spot Testnet day-trading agent

This adds an **experimental, long-only spot agent** for BTC/USDT, ETH/USDT, and SOL/USDT. It uses the repository's existing multi-timeframe indicator strategy and market data. It has no model-training or guaranteed-profit mechanism: markets are uncertain, and testnet results do not prove profitability.

## Safety first

- **Testnet only.** The exchange is always placed in CCXT sandbox mode; this project has no live-trading switch or live endpoint configuration.
- Default command is scan-only. Orders require the explicit `--execute-testnet` flag and `BINANCE_TESTNET=1`.
- Use Binance **Spot Test Network** API credentials only. Never put keys in source, config, or chat. Keep withdrawal permissions disabled.
- Spot-only, long-only, no leverage. One position at a time; risk and notional caps plus a daily loss-entry halt are configured in `binance_testnet.yaml`.
- The stop/target are monitored by this process, **not held as exchange-side protective orders**. A crash, connectivity loss, or process shutdown can leave a testnet position open. This design must not be used with real funds.
- The agent tries to close a position on the next UTC day, but cannot guarantee a fill or a close if the exchange/network is unavailable. Testnet orders can behave differently from production.

## Install and configure

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\\Scripts\\activate
pip install -r trade_requirements.txt
```

Create API credentials from Binance Spot Test Network and export them in the shell that runs the agent:

```bash
export BINANCE_API_KEY='your-testnet-key'
export BINANCE_API_SECRET='your-testnet-secret'
export BINANCE_TESTNET=1
```

Do not use production Binance keys. The agent unconditionally enables CCXT sandbox mode. Keep the keys in a local environment or secret manager, never commit them.

## Run

Scan the most recent **closed** candles without placing orders:

```bash
python binance_testnet_agent.py
```

Start the continuously polling testnet agent, which can submit spot market orders:

```bash
python binance_testnet_agent.py --execute-testnet
```

Stop with Ctrl+C. Ctrl+C does not close an open position; inspect `data/binance_testnet_state.json` and the Spot Testnet account, then restart the agent or close the position manually on testnet. State and JSONL trade events are under `data/` and are git-ignored.

## Strategy and limitations

Signals are generated by the existing EMA/RSI multi-timeframe strategy on closed 30-minute candles. Position size uses ATR-based stop distance, a risk fraction, and a notional cap. The loop checks prices at its polling interval and sends market orders; gaps, slippage, fees, precision limits, and partial fills can materially change outcomes. The daily boundary is UTC. Losses, profitable days, or the agent's learning/development cannot be guaranteed. This version does not train itself or automatically alter parameters; any strategy change should be evaluated on separate historical data and then on testnet before use.

The initial version is for engineering and execution-path testing only. Review the code, test order sizing and manual recovery, and verify your testnet account before enabling order execution.
